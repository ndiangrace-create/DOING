# DOING 2.0｜Market 心智操作路徑下鑽

日期：2026-08-22

## 本輪目的

依使用者提供的《2BL 營運世界樹｜心智圖》繼續往下展開 DOING Market，不重做既有七步主線。

## 前台攤商

固定主線仍為：活動探索 → 會員 → 報名 → 付款 → 排位 → 現場 → 歷史紀錄。

本輪往下一層補上：
- 首頁／活動列表／日曆 → 活動／場次卡 → 場次詳情。
- 會員驗證與首次／資料不完整補齊。
- 報名表 → 合約 → 送出 → 我的報名。
- 正式應繳 → 付款回報 → 主辦確認付款。
- 正式排位資料與設備資訊。
- 行前通知／大群組 → 活動當日報到 → 撤場／押金。
- 過往活動、退款／轉場／活動金、取消未繳費釋放名額／位置。

## 後台主辦

固定主線仍為：場次設定 → 待辦 → 審核 → 付款 → 排位 → 退款 → 財務結案。

本輪往下一層補上：
- 場次基本資料、費用與設備、報名規則、報名排程／分波錄取。
- 全部待辦與單場待辦。
- 待審核、錄取／備取／未錄取。
- 付款待確認、確認付款、已繳費／行前。
- 排位與設備／配置。
- 取消／退款、轉場／活動金、不可抗力。
- 收入／退款、支出／設備、結算／分潤。
- 管理支援仍放在 Market 工作區，不新增獨立後台。

## 系統閉環

固定閉環仍為：按鈕／操作 → Core／API → Supabase SSOT → 重讀正式資料 → 畫面同步。

本輪補上會員、活動／場次、報名、付款／退款、財務／結案、每日營運／排位與錯誤／稽核等下層節點。

## 安全鎖

- 不修改 2BL。
- 不新增第二套會員、報名、付款、排位、退款或財務資料來源。
- 不修改 Worker／Supabase 正式資料。
- 未完成正式真人驗證的節點維持黃燈／待驗證或尚未做，不冒充完成。
