## 下一階段唯一主線

完成 Market 市集操作介面，逐節點把世界樹黃燈做成綠燈。

規則：
1. 不再更改已確認的操作骨架。
2. 介面必須沿世界樹順序實作，不另開平行流程。
3. DOING 登入維持 LINE／正式會員機制。
4. Supabase 維持唯一正式資料來源。
5. 設定、現場、會員、Workspace 層級不得搬動。
6. 小功能優先在同一工作頁以分頁／抽屜／彈窗處理，不增加不必要頁面。
7. 每完成一段需驗證按鈕、權限、API、資料讀寫、重讀與畫面同步。
8. 未做正式驗證的節點不得標成完成。
9. 不修改 2BL；2BL 僅作操作路徑參考。
10. 下一階段以介面完成度為主，不重做已通過的會員、登入、Core、SSOT 與既有正式能力。
